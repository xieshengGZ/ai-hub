创建后常驻
创建后由该机器的 Daemon 按需或常驻拉起；默认不进任何团队。
已删除的 agent
删除只是隐藏，历史消息与产出还在。可以恢复；彻底清除会删掉消息、任务、产出记录和壳自己的状态目录，但工作目录一律保留（里面可能有你的文件），不可恢复。
技能
技能会写进这个 agent 的目录并在启动时加载；开关立即生效，下一次对话使用新配置。
技能存在每台机器的共享库（~/aihub/skills）。「安装」= 在 agent 目录下建一个链接；「卸载」只删链接；只有没有任何 agent 装着时才能从库里删除。
安全 / 两步验证
开启后登录需要「口令 + 认证器 6 位动态码」；备用码可一次性替代动态码。
模型配置
每条填三样：base url、模型名、sk。sk 只在中枢保存，列表里只显示后四位。
改模型只影响选中它的 agent；正在跑的会话会在下一轮重启后生效。
选择模型
切换后保留对话历史，从下一轮开始用新模型回答。
团队
