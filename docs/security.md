# 安全

这是一个**单人单口令**的内部工具，默认假设部署在你信任的网络里。下面按威胁模型列清楚，
上手前请逐条过一遍。

## 信任边界

```
互联网 ──> 反向代理 ──> Hub（口令 + cookie）
                          │
                          └── host token ──> Daemon（以运行用户身份执行 agent）
```

- **Hub 的口令 = 全部权限**：能登录就能建 agent、派活、读所有会话和文件。
- **host token = 该机器的执行权**：拿到 token 就能伪装 Daemon 领任务；反过来，Hub 被攻破等于所有接入机器被攻破。
- **agent 的权限 = Daemon 运行用户的权限**：agent 能读写该用户能读写的一切，能执行命令。

## 部署建议

1. **只走 HTTPS**，Hub 只监听 `127.0.0.1`，由 nginx/caddy 终止 TLS。
2. **强口令**，别用示例里的 `change-me`；建议再加一层来源 IP 白名单或 VPN。
3. **Daemon 用低权限账号**跑（示例里是 `aihub`），不要用 root。
4. **接入脚本里的 token 是一次性凭据**，会出现在 shell history、进程列表里；装完可以点「换 token」再下发一次。
5. **定期换口令**：改 `config.json` 后重启 Hub，旧 cookie 因为签名密钥变了会全部失效吗？——不会，cookie 是独立签名的，改口令不影响已签发的 cookie，必要时手动清浏览器 cookie。

## 已知的弱点

| 项 | 说明 | 建议 |
|---|---|---|
| 单口令 | 没有用户体系、没有审计日志 | 只给自己/小团队用；需要多人时加反向代理的 basic auth 按人分发 |
| cookie 无刷新 | 有效期 30 天，登出只清本地 | 敏感环境缩短 `Max-Age` |
| 上传无病毒扫描 | 任何文件都能传，agent 会读 | 不信任来源别往上丢 |
| agent 可执行命令 | 设计如此 | 用低权限用户 + 容器/沙箱隔离 |
| 长轮询 | 20 秒一轮，任务多时延迟 | 需要更低延迟再换 WebSocket |
| 无速率限制 | 登录接口可被暴力尝试 | 公网部署务必在代理层加限速 |

## 数据

- SQLite 与附件都在 `data` 目录，备份=复制该目录（停服务后复制最稳）。
- 保留期：消息 180 天、产出 30 天、未取附件 7 天，在 `cleanup_loop` 里改。
- 删除 agent 是软删除（`deleted=1`），「彻底清除」才会连消息、任务、文件一起删。
